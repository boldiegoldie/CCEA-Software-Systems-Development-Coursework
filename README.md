# CCEA Coursework archive
This repo has both my AS & A2 coursework pieces for the CCEA SSD spec starting Sept 2016.

Both projects are anonymised hence the weirdly long names. Both projects also include the write-ups which are admittidly way *way* too big lol, but it'll maybe be useful to you

I scored well in both of these pieces, so feel free to use them as reference! 

I don't care about credit, feel free to include it if you want but as you almost certainly know, CCEA moderaters are the spawn of satan and will take every oppertunity to decimate your marks so I would give them as little chances as possible and idk how they would react to using past coursework submissions as reference.


Both projects target .NET 4.7.2 and should be opened in Visual Studio 2019. The AS coursework was written in VS2022 so it would work fine in that, but the A2 requires CrystalReports and SQLServer 2016, which are only on VS2019.
